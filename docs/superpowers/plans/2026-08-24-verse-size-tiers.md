# Verse Size Tiers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give each widget size its own pool of verses, tiered by length, so larger widgets can show passages long enough to stand on their own.

**Architecture:** Each verse carries a `tier` (0 short, 1 medium, 2 long) computed at fetch time from its measured length. `VerseSizeClass` maps a widget family to the highest tier it may draw from; pools nest, so large sees everything and small sees only tier 0. Each pool runs the existing seeded Fisher-Yates shuffle under its own seed, so the three sizes do not advance in lockstep.

**Tech Stack:** Swift 5 / SwiftUI / WidgetKit, XCTest, zsh + curl + jq for the fetch script, XcodeGen for the project file.

**Spec:** `docs/superpowers/specs/2026-08-24-verse-curation-and-size-tiers-design.md`

## Global Constraints

- Requires macOS 26 and Xcode 26. The `.xcodeproj` is generated by XcodeGen and is not committed; run `xcodegen generate` before building.
- Configuration parameters must stay primitive (`Bool`, `String`). The project is ad-hoc signed, and `linkd` on macOS 26 silently decodes `AppEnum` parameters to their defaults. Do not introduce an `AppEnum`.
- Scripture is never truncated mid-sentence. `AyahWidget/VerseView.swift:157` records this; smaller type is preferred to a cut.
- Text length is measured in **Unicode scalars** on both sides: `unicodeScalars.count` in Swift, `${#var}` in zsh. Swift's `String.count` counts grapheme clusters and would disagree with the script on Uthmani text, which carries many combining marks. Never use `.count` for a tier threshold.
- Arabic is `quran-uthmani` and English is `en.sahih` from `api.alquran.cloud`. Do not change sources.
- Provisional tier caps, in Unicode scalars, superseded by Task 5: tier 0 <= 200, tier 1 <= 350, tier 2 <= 700. Both Arabic and English must clear the cap.
- No em dashes in any user-facing copy or documentation. Rewrite the sentence instead.
- Commits are authored as Malek Albdoor <malekalbdoor10@gmail.com> with no AI co-author trailer.

**Scope:** This plan covers phase 1 of the spec, the mechanism, plus the phase 2 calibration decision. The phase 2 content curation (auditing the 365 for fragments, adding long-tier passages) is a separate effort that depends on Task 5's measured thresholds and needs verse-by-verse human review. It gets its own plan.

    case large
